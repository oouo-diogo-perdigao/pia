# abrir navegador

Ative dizendo **comando abrir navegador**.

Projeto independente de skill PIA. `plugin.toml` define a frase e o entrypoint. A função `execute` recebe somente as APIs que declara por nome. Veja [o contrato das APIs](../../../docs/SKILLS.md).


## Manifesto e idioma

Os metadados desta extensão ficam em `pia.json` e os textos em `lang/pt-BR.json`. Consulte o [padrão de extensões e variáveis tipadas](../../../docs/EXTENSIONS.md) para criar telas, campos de configuração e integrações compartilhadas.
