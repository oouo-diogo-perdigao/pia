# IsekaiZero / Browser

Projeto de userscript independente. Instale `isekai0.user.js` no Tampermonkey. A lógica e a URL local da PIA foram preservadas. Este projeto não é uma skill Python e não é carregado pelo servidor.


## Manifesto e idioma

Os metadados desta extensão ficam em `pia.json` e os textos em `lang/pt-BR.json`. Consulte o [padrão de extensões e variáveis tipadas](../../../docs/EXTENSIONS.md) para criar telas, campos de configuração e integrações compartilhadas.
